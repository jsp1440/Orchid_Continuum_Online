# 🌺 Orchid Culture Sheet Generator

A stunning, portfolio-quality front-end interface for generating beautiful, evidence-based orchid culture sheets tailored to your species and climate.

## ✨ Features

### 🎨 7 Interface Themes
- Botanical Green
- Orchid Purple
- Minimalist White
- Dark Conservatory
- Tropical Sunset
- Scientific Blue
- Fantasy Garden

### 📊 Comprehensive Culture Information
- Temperature (day/night ranges)
- Light requirements (foot-candles)
- Water frequency
- Humidity targets
- Potting media recommendations
- Fertilizer schedules

### 🐝 Educational Sections
- **Pollinators**: Learn about the insects and birds that visit orchids in the wild
- **Companion Plants**: Discover plants that share the same habitat

### 🗺️ Interactive Features
- Species search with autocomplete
- GPS location capture for climate comparison
- Customizable section toggles
- Print-optimized culture sheets
- Collection library for saved sheets
- Embeddable widget code generator

### 📱 Progressive Web App
- Offline capability with service worker
- Install prompt for mobile devices
- Responsive design for all screen sizes

## 🚀 Getting Started

This is a React + TypeScript + Tailwind CSS application. The backend API is already complete - this is the front-end interface only.

### Installation

```bash
npm install
npm run dev
```

### API Integration

The app is designed to call your existing backend API. Update the API endpoints in the component files to connect to your orchid database.

## 🎯 Usage

1. **Search** - Type a genus or species name
2. **Location** - Use GPS or enter your city
3. **Sections** - Toggle which information to include
4. **Themes** - Choose your preferred visual style
5. **Generate** - Create your custom culture sheet
6. **Save** - Add sheets to your collection
7. **Print** - Get a print-ready version
8. **Share** - Copy a shareable link

## 🏗️ Architecture

- **React** - Component-based UI
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first styling
- **CSS Variables** - Dynamic theming
- **PWA** - Offline-first architecture
