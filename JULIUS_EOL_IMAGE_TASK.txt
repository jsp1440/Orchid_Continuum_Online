Download EOL images for orchid species and upload them to Google Drive with proper metadata alignment.

STEP 1: Find EOL Page IDs for Species Missing Them
Run this query to get priority species (those with local GBIF images but missing EOL):

SELECT 
    ot.id as taxonomy_id,
    ot.genus,
    ot.species,
    ot.scientific_name,
    ot.eol_page_id,
    COUNT(DISTINCT oi.id) as gbif_image_count
FROM orchid_taxonomy ot
INNER JOIN orchid_images oi ON ot.id = oi.taxonomy_id
WHERE ot.eol_page_id IS NULL
GROUP BY ot.id, ot.genus, ot.species, ot.scientific_name, ot.eol_page_id
ORDER BY gbif_image_count DESC
LIMIT 100;
