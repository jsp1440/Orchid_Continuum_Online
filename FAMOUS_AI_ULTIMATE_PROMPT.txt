🔌 API INTEGRATION (Already Built - Just Call!)

Base URL: https://orchid-continuum-online.onrender.com

1. Search Species
   GET /api/species/search?query={term}

2. Generate Culture Sheet
   POST /api/culture-sheets/generate
   Body: {taxonomy_id, latitude, longitude, city, country, sections, 
          artwork_style, interface_theme, sheet_theme}

3. Get Distribution Data
   GET /api/species/{taxonomy_id}/distribution

4. Get Collection Points
   GET /api/species/{taxonomy_id}/collection-points

5. Save to Collection
   POST /api/my-collection/save

6. Get My Collection
   GET /api/my-collection?user_id={id}

7. Browse Public Library
   GET /api/public-library?sort=popular&page=1

8. Get Data Sources
   GET /api/culture-sheets/{taxonomy_id}/sources
