## 🎨 CANVA DESIGN TIPS

### Color Scheme (Match OCU branding):
- **Background:** Dark purple/black gradient
- **Text:** White with dark shadow (for readability)
- **Accents:** Pink/orchid purple
- **Arrows:** Bright yellow or white (high contrast)

### Typography:
- **Titles:** Bold, 60-72pt
- **Definitions:** Regular, 32-40pt
- **Labels:** Medium, 24-30pt

### Layout:
```
┌─────────────────────────────────────┐
│  TERM NAME (Title, top center)     │
│                                     │
│     [ILLUSTRATION/PHOTO]           │
│         with arrows/labels         │
│                                     │
│  Definition text (bottom, overlay) │
└─────────────────────────────────────┘
```

### Effects to Use:
- Drop shadow on text (black, 50% opacity)
- Dark overlay behind text (for readability)
- Arrow shapes from Canva elements
- Vignette on photo edges (optional)

## 💡 ALTERNATIVE: USE EXISTING DATABASE IMAGES

**Instead of Canva, use your 11,717 database images:**

Query to find good images:
```sql
SELECT 
  oi.genus,
  oi.scientific_name,
  oi.image_url,
  oi.photographer,
  oi.license
FROM orchid_images oi
WHERE oi.image_url IS NOT NULL
  AND oi.license LIKE '%CC%'  -- Creative Commons
  AND oi.genus IN ('Cattleya', 'Phalaenopsis', 'Paphiopedilum', 'Dendrobium')
ORDER BY RANDOM()
LIMIT 20;
```

**Advantage:** Real specimens with scientific metadata!
