⚡ QUICK START:
--------------
1. Extract this zip file to a folder on your Mac (e.g., ~/orchid_downloads/)
2. Open Terminal and navigate to that folder: cd ~/orchid_downloads/
3. Install dependencies: pip3 install -r mac_requirements.txt
4. Set your DATABASE_URL (from Replit Secrets)
5. Run: python3 download_to_static.py
6. Let it run overnight!
