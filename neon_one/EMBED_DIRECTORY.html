📖 Quick Start Guide

  1. Choose a widget from the table above
  2. Open the file (click the file link)
  3. Edit CONFIG section - Set BASE_URL to your deployed app URL
  4. Copy entire file contents (Ctrl+A, Ctrl+C)
  5. Paste into Neon One HTML content block
  6. Save & publish!

💰 Cost Flags Legend

  • DB - Requires backend database query (minimal cost)
  • AI - Uses AI tokens (currently disabled by default, no cost)
  • Weather API - Uses free OpenWeather API
  • FREE API - Uses free GBIF API
  • None - Fully client-side, no API calls
