# How to Upload to GitHub

Go to https://github.com/new and create a new repo called "orchid-harvester"

Then click "uploading an existing file" and upload these files one by one:

## Files to Upload:

1. RESERVED_VM_SUPERVISOR.py
2. julius_multi_source_worker.py  
3. continuous_job_seeder.py
4. requirements.txt
5. render.yaml
6. launcher_vm.sh
7. deploy_config.py

## How to Download Each File:

1. Click on the filename in the file list on the right
2. The file will open in the editor
3. Click the three dots (...) menu at the top right
4. Select "Download"

OR use the file browser:
1. Right-click on each file in the file list
2. Select "Download"

After downloading all 7 files, upload them to GitHub.
