🔄 System Architecture

Julius AI Scraper → Discovers orchid data from iNaturalist, GBIF, Flickr → Writes to julius_ingest_events

Database Triggers → Automatically create tasks in pipeline_tasks → Send NOTIFY events

Pipeline Workers → Listen for NOTIFY → Process images → Save to image_assets (triggers metrics update)

Central Orchestrator → Monitors workers → Refills queues → Restarts dead workers → Runs every 60 seconds

✅ Self-Sustaining Loop: No human intervention required!
