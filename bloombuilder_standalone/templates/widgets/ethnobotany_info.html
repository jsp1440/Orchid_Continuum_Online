🌿 Ethnobotany Widget Package

Embeddable research widgets for Neon One CMS and other platforms

📦 Available Widgets

1. Medicinal Orchid Interactive Map

Interactive global map showing medicinal orchids by region with research data from academic sources.

  • Interactive Leaflet map with clustering
  • Filter by genus
  • Click markers to see traditional uses, medicinal applications, and active compounds
  • 110+ genera with research data
  • Mobile responsive
Preview Map Widget

2. Ethnobotany Timeline

Visual timeline showing orchid ethnobotanical knowledge through history from ancient to contemporary periods.

  • 5 historical periods with animated timeline
  • 110+ genera organized by cultural/historical context
  • Interactive genus pills with hover effects
  • Beautiful gradient design
  • Mobile responsive
Preview Timeline Widget

🔗 Embedding Instructions

For Neon One CMS

Use these iframe codes to embed the widgets in your Neon One website:

Medicinal Orchid Map:

<iframe 
  src="https://your-render-url.onrender.com/widgets/ethnobotany/medicinal-map-embed" 
  width="100%" 
  height="800" 
  frameborder="0" 
  style="border-radius: 12px; box-shadow: 0 4px 20px rgba(0,0,0,0.1);"
></iframe>

Ethnobotany Timeline:

<iframe 
  src="https://your-render-url.onrender.com/widgets/ethnobotany/timeline-embed" 
  width="100%" 
  height="1000" 
  frameborder="0" 
  style="border-radius: 12px; box-shadow: 0 4px 20px rgba(0,0,0,0.1);"
></iframe>
📝 Note: Replace your-render-url.onrender.com with your actual Render deployment URL after pushing to GitHub and deploying.

For Other Platforms (WordPress, Squarespace, etc.)

These widgets work on any platform that supports iframe embeds. Simply paste the iframe code into your HTML/embed block.

🚀 Deployment Steps

  1. Commit to GitHub: Push all widget files to your repository
  2. Deploy on Render: Render will auto-deploy from your GitHub repo
  3. Update URLs: Replace the placeholder URLs in the iframe codes with your actual Render URL
  4. Embed in Neon One: Paste the updated iframe codes into your Neon One CMS pages
  5. Test: Verify the widgets display correctly and are responsive

⚙️ API Endpoints

These endpoints power the widgets and can be used for custom integrations:

GET /widgets/ethnobotany/api/map-data
GET /widgets/ethnobotany/api/map-data?genus=Dendrobium

Response format:

{
  "success": true,
  "locations": [
    {
      "genus": "Dendrobium",
      "lat": 15.0,
      "lng": 100.0,
      "data": {
        "genus": "Dendrobium",
        "species": "nobile",
        "location": "Thailand",
        "traditional_uses": [...],
        "medicinal_uses": [...],
        "active_compounds": [...],
        "cultural_areas": [...],
        "source": "Medicinal Orchids of Asia (Teoh, 2016)"
      }
    }
  ],
  "count": 25
}
