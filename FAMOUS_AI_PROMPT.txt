🔌 API INTEGRATION (Endpoints Already Built - Just Call Them!)

Base URL: https://orchid-continuum-online.onrender.com

1. Search Species
   GET /api/species/search?query={term}
   Returns: [{taxonomy_id, species_name, common_name, genus}]

2. Generate Culture Sheet
   POST /api/culture-sheets/generate
   Body: {
     taxonomy_id: 7905,
     latitude: 34.0522,
     longitude: -118.2437,
     city: "Los Angeles",
     country: "USA",
     sections: ["temperature", "light", "water", "humidity", "potting", 
                "fertilizer", "pollinators", "companions"],
     artwork_style: "artistic", // or "scientific", "fantasy", "scifi"
     interface_theme: "scientific",
     sheet_theme: "botanical"
   }
   Returns: {
     sheet_id, species_name, genus,
     temperature: {...}, light: {...}, water: {...},
     pollinators: {...}, companions: {...},
     distribution_map: {...}, collection_points: [...],
     climate_comparison: {...}, artwork_url: "..."
   }

3. Get Distribution Data
   GET /api/species/{taxonomy_id}/distribution
   Returns: {
     native_countries: [...],
     distribution_geojson: {...},
     elevation_range: {min, max},
     climate_zones: [...],
     suggested_regional_theme: "south_american"
   }

4. Get Collection Points
   GET /api/species/{taxonomy_id}/collection-points
   Returns: {
     points: [{lat, lng, source, date, photo_url, elevation}]
   }

5. Save to Collection
   POST /api/my-collection/save
   Body: {sheet_id, user_id, nickname}

6. Get My Collection
   GET /api/my-collection?user_id={id}

7. Browse Public Library
   GET /api/public-library?sort=popular&page=1

8. Get Data Sources
   GET /api/culture-sheets/{taxonomy_id}/sources

Use CSS custom properties:
```css
:root {
  --primary-bg: #1a1a2e;
  --accent: #9d4edd;
  --text: #f8f9fa;
}

.theme-fantasy {
  --primary-bg: #0f0f23;
  --accent: #00ffcc;
  --text: #e0e0e0;
}
```

JavaScript theme switcher:
```javascript
function setTheme(type, themeName) {
  // type = 'interface', 'sheet', or 'regional'
  document.body.classList.remove(...existingThemes);
  document.body.classList.add(`${type}-${themeName}`);
  loadThemeCSS(`${type}/${themeName}.css`);
  localStorage.setItem(`${type}_theme`, themeName);
}
```
